"""Stage 1 — Script.

Run a raw thought through ChatGPT and get back a full episode built in the
show's structure:

    hook → intro → part 1 → ad → part 2 → outro

Plus title, tagline, Scripture, a summary, and three pull-quotes flagged as reel
candidates. Each segment is voiced separately in CloneVoice, so we keep them as
distinct pieces of text all the way through.

Output is written into episode.json under "episode".
"""

from __future__ import annotations

import json
import re

from ..config import SEGMENTS, SEGMENT_LABELS, Config, log
from ..normalize import normalize_episode, stringify as _stringify
from ..project import Project

SYSTEM_PROMPT = """\
You are the writer for "Where Was the Church", a Christian history podcast hosted by Pastor
Billy Daws. Each episode revisits a real moment in history, asks "Where was the church?", and
weighs it honestly: what the church got right, where it failed, what the faithful remnant did,
and what we must never repeat. Reverent, weighty, honest, pastoral. It ends in hope.

VOICE — the way Billy talks:
- Vivid and CONCRETE. Short lines that land. Show, do not tell. A specific fact or scene always
  beats an abstraction: "The German Christians won two-thirds of the 1933 church elections" beats
  "the church compromised."
- Plain words. No throat-clearing. NEVER restate a point you already made — if a paragraph adds
  no new fact, name, or scene, it does not belong.

BANNED PHRASES — do NOT use these or anything close; using them is a failure. Replace each with a
concrete fact: "beacon" (of light/hope/resistance), "light in the darkness", "city on a hill",
"cautionary tale", "stand firm", "speak truth to power", "conscience of society/state", "no
matter the cost", "vigilant"/"vigilance", "the very soul of a nation".

SPECIFICITY IS THE WHOLE SHOW — non-negotiable:
- Name real people, places, dates, movements, documents, and NUMBERS. Vague history is a FAILED
  episode. When the topic is the German church under Hitler you MUST include the hard specifics:
  the July 1933 church elections the "German Christians" won by about two-thirds; Reich Bishop
  Ludwig Muller; the Aryan Paragraph that expelled clergy of Jewish descent; the attempt to
  "de-Judaize" the Bible; pastors closing sermons with "Heil Hitler"; the 1934 Barmen Declaration;
  Bonhoeffer executed at Flossenburg in 1945; Niemoller imprisoned 1938-1945. Use the equivalent
  hard specifics for whatever event this episode covers.
- ACCURACY IS SACRED: never invent a fact, date, name, quotation, or Scripture reference. If you
  are not certain of a detail, use one you ARE sure of. Handle grave subjects with gravity.

Write a complete episode in this exact structure and return STRICT JSON:

{
  "title": "the event or subject, short and specific",
  "tagline": "one vivid sentence",
  "series": "the era/unit this belongs to, or empty string",
  "scripture": { "ref": "Book chap:verse (KJV)", "text": "the exact verse text" },
  "summary": "2-3 sentences on what this episode examines",
  "segments": {
    "hook":  "8-15 seconds. Name the subject plainly. One sharp line. Do NOT answer it.",
    "intro": "Welcome + name the show + the moment we are examining today.",
    "part1": "TELL THE HISTORY and where the church FAILED, concrete and scene by scene, with real names, dates, and numbers. Reporting, not a sermon. Do NOT moralize at length, do NOT preview the remnant, do NOT write a conclusion. End on ONE short turning line that points to Part 2. LONG and rich, see LENGTH.",
    "ad":    "A warm 20-30 second ad slot, follow the AD INSTRUCTION in the user message exactly.",
    "part2": "Build it in four moves, then STOP. (1) The faithful remnant: named people and what they concretely did and risked. (2) THE BIBLICAL MEASURE: read the episode Scripture ALOUD in Billy's voice — name the reference and speak the verse words in full — then show plainly, in a sentence or two, how that Word judged the exact choice the church faced. This is the heart of the show: history laid against Scripture. (3) THE VERDICT: exactly THREE short, sharp sentences naming what the church must never repeat, each tied to a concrete failure from Part 1. (4) ONE clear, doable action for the church today. Do NOT add closing paragraphs of general reflection after the action, the outro closes the show. LONG and rich, see LENGTH.",
    "outro": "Land it in one sober, hopeful breath, then invite them to follow the show."
  },
  "reels": [
    { "quote": "a single punchy line taken VERBATIM from a segment",
      "segment": "part1" }
  ]
}

Rules:
- SCRIPTURE: the "scripture" verse must be one that directly judges the choice the church faced in THIS episode. It is READ ALOUD inside Part 2 (the Biblical Measure move), so it must be a real verse quoted accurately, not paraphrased. The same reference and words that appear in "scripture" must be spoken in the Part 2 text.
- LENGTH: Part 1 and Part 2 each about 6,000-6,800 characters, CLOSE in length, never over 6,800.
  Fill length with SUBSTANCE, more named facts, dates, and story, NEVER by restating an idea or
  adding general reflection. If you are repeating yourself, you are done: add a new fact or stop.
- TITLE: fresh and specific to THIS event. Do NOT reuse the host book titles (listed in the user
  message to avoid).
- Spoken words only, no stage directions, no "[music]".

- Follow the VOICE CAST in the user message: some segments are the host, some the co-host. Write each

- "segment" must be one of: hook, intro, part1, ad, part2, outro.
- Return ONLY the JSON object. No markdown, no commentary.

def run(project: Project, cfg: Config) -> None:
    cfg.require("openai_api_key")
    from openai import OpenAI

    client = OpenAI(api_key=cfg.openai_api_key)
    idea = project.data["idea"]

    # Pick which Amazon book the ad promotes (chosen on the CLI, else the first
    # in the drop list, else a house spot).
    ad_book = cfg.find_book(project.data.get("ad_book"))
    if ad_book:
        project.data["ad_book_used"] = ad_book
        desc = f" About the book: {ad_book['desc']}" if ad_book.get("desc") else ""
        ad_instruction = (
            f"AD INSTRUCTION: Make the ad a warm 20-30 second promo for the "
            f"host's book, \"{ad_book['title']}\".{desc} Tie it naturally to "
            f"today's theme and invite listeners to grab a copy. Refer to the book "
            f"by its title and say they'll find it on Amazon — the link is in the "
            f"description and pinned comment. Do NOT read any web address aloud."
        )
        log("script", f"ad promotes: {ad_book['title']}")
    else:
        ad_instruction = (
            "AD INSTRUCTION: No book selected — make the ad a house spot: invite "
            "listeners to follow, share the episode, and leave a review. Do not "
            "mention any outside brand."
        )
        log("script", "ad: house spot (no Amazon book selected)")

    # Tell the writer who voices which segment (two-voice show, if configured).
    cast_instruction = _voice_cast(cfg)
    length_instruction = _length_targets(cfg)
    title_instruction = _title_rule(cfg)

    log("script", f"asking {cfg.openai_model} to write the 6-part episode…")
    resp = client.chat.completions.create(
        model=cfg.openai_model,
        response_format={"type": "json_object"},
        temperature=0.8,
        max_tokens=8000,  # room for a 15-18 min Part 1 + Part 2
        messages=[
            {"role": "system", "content": SYSTEM_PROMPT},
            {"role": "user", "content":
                f"The idea for this episode:\n\n{idea}\n\n{length_instruction}\n\n"
                f"{title_instruction}\n\n{cast_instruction}\n\n{ad_instruction}"},
        ],
    )
    episode = json.loads(resp.choices[0].message.content)
    normalize_episode(episode)
    _validate(episode)

    # ChatGPT tends to under-write long sections. If Part 1 + Part 2 came out
    # short of the teaching-time target, expand them (and re-pick reel quotes).
    _ensure_teaching_length(client, cfg, episode)

    # Editor pass — the reliable fix: strip cliches, cut padding, sharpen the
    # verdict, and force concrete facts. Runs once, then a second time only if
    # any banned phrase survived.
    _polish_episode(client, cfg, episode)
    _left = _remaining_cliches(
        episode["segments"].get("part1", "") + " " + episode["segments"].get("part2", ""))
    if _left:
        log("script", "editor: second pass to remove leftover cliches: " + ", ".join(_left))
        _polish_episode(client, cfg, episode, focus_cliches=_left)

    # Safety net: strip any web address that slipped into a spoken segment, so
    # CloneVoice never reads a URL out letter-by-letter. (Links live in the text
    # descriptions / pinned comment, not the audio.)
    scrubbed = 0
    for seg in SEGMENTS:
        cleaned, hits = _strip_spoken_urls(episode["segments"].get(seg, ""))
        episode["segments"][seg] = cleaned
        scrubbed += hits
    if scrubbed:
        log("script", f"cleaned {scrubbed} spoken link(s) out of the script.")

    # Measure each segment (word count + estimated spoken time) so you can see
    # how big ChatGPT made Part 1 and Part 2 before you voice them.
    episode["segment_stats"] = {
        seg: _measure(text) for seg, text in episode["segments"].items()
    }

    # Split segments into CloneVoice-sized clips (long parts become 2+ clips).
    from ..clips import build_clips
    episode["clips"] = build_clips(episode, cfg)

    project.data["episode"] = episode
    project.mark_done("script")

    stats = episode["segment_stats"]
    total_words = sum(s["words"] for s in stats.values())
    total_min = sum(s["est_seconds"] for s in stats.values()) / 60
    log("script", f"'{episode['title']}' — 6 segments, ~{total_words} words, "
                  f"~{total_min:.1f} min, {len(episode['reels'])} reels drafted.")
    for seg in ("part1", "part2"):
        s = stats[seg]
        log("script", f"  {seg}: {s['words']} words (~{s['est_seconds']/60:.1f} min)")


def _length_targets(cfg: Config, wpm: int = 150) -> str:
    """Build a per-segment TARGET LENGTHS block from show.json settings."""
    lines = ["TARGET LENGTHS — aim for these:"]
    for seg in ("hook", "intro", "ad", "outro"):
        secs = cfg.segment_seconds.get(seg)
        if secs:
            words = round(secs / 60 * wpm)
            lines.append(f"- {SEGMENT_LABELS[seg]}: ~{secs} seconds (about {words} words)")
    lo_c, hi_c = (cfg.teaching_chars + [6000, 6800])[:2]
    lines.append(
        f"- Part 1: about {lo_c}-{hi_c} characters (a long, full teaching movement — many paragraphs)"
    )
    lines.append(
        f"- Part 2: about {lo_c}-{hi_c} characters, and CLOSE in length to Part 1 (balanced)"
    )
    lines.append(
        f"- Do NOT exceed {hi_c} characters in either part — that keeps each to one voice clip."
    )
    return "\n".join(lines)


def _title_rule(cfg: Config) -> str:
    """Tell the writer not to reuse the host's book titles as the episode title."""
    titles = [b.get("title", "") for b in (cfg.amazon_books or []) if b.get("title")]
    base = "TITLE: give this episode a fresh, specific title for THIS teaching."
    if not titles:
        return base
    listed = "; ".join(f"\"{t}\"" for t in titles)
    return base + " Do NOT reuse or closely echo any of the host's book titles: " + listed + "."


def _voice_cast(cfg: Config) -> str:
    """Describe who speaks each segment, so the writer matches each voice."""
    if not cfg.cohost or not cfg.segment_voices:
        return "VOICE CAST: One host voices every segment."
    host_segs = [SEGMENT_LABELS[s] for s in SEGMENTS if cfg.voice_role(s) == "host"]
    co_segs = [SEGMENT_LABELS[s] for s in SEGMENTS if cfg.voice_role(s) == "cohost"]
    return (
        "VOICE CAST — this show has two voices:\n"
        f"- {cfg.show_host} (the teacher) speaks: {', '.join(host_segs)}. "
        "Write these in his warm, teaching voice.\n"
        f"- {cfg.cohost} (the co-host / announcer) speaks: {', '.join(co_segs)}. "
        f"Write these as {cfg.cohost}: welcome listeners, introduce {cfg.show_host} "
        f"in the third person, read the ad, and close the show. {cfg.cohost} is the "
        "friendly voice around the teaching, not the teacher."
    )


def _ensure_teaching_length(client, cfg, episode, tries: int = 3) -> None:
    """Bring any SHORT teaching part up into range — without touching a part that's
    already long enough (so a good part can't be over-expanded past one clip)."""
    lo_c, hi_c = (cfg.teaching_chars or [6000, 6800])[:2]
    floor = max(4800, lo_c - 800)  # gentle floor: a solid-length part is never force-padded
    for _ in range(tries):
        c1 = len(episode["segments"].get("part1", ""))
        c2 = len(episode["segments"].get("part2", ""))
        need1, need2 = c1 < floor, c2 < floor
        if not need1 and not need2:
            break
        which = " and ".join(n for n, ok in (("Part 1", need1), ("Part 2", need2)) if ok)
        log("script", f"teaching is {c1}/{c2} chars (target {lo_c}-{hi_c} each); expanding {which}…")
        p1_note = "TOO SHORT — expand this" if need1 else "already good — keep unchanged"
        p2_note = "TOO SHORT — expand this" if need2 else "already good — keep unchanged"
        try:
            resp = client.chat.completions.create(
                model=cfg.openai_model,
                response_format={"type": "json_object"},
                temperature=0.7,
                max_tokens=8000,
                messages=[
                    {"role": "system", "content":
                        "You lengthen a history podcast's teaching ONLY by adding new concrete facts, names, dates, and story, never by "
                        "restating a point or adding general reflection. Keep it vivid and plain, no cliches like beacon, "
                        "stand firm, vigilant, or light in the darkness. Keep the host's warm, plain voice."},
                    {"role": "user", "content":
                        f"Episode: {episode['title']}\n"
                        f"Scripture: {episode['scripture'].get('ref', '')}\n"
                        f"Summary: {episode.get('summary', '')}\n\n"
                        f"Expand ONLY the part(s) marked TOO SHORT so each reaches "
                        f"{lo_c}-{hi_c} characters. Do NOT exceed {hi_c} characters in either "
                        f"part, and keep the two parts CLOSE in length. Leave a part marked "
                        f"'keep unchanged' exactly as it is. Add real NEW paragraphs of concrete history (names, dates, specifics, story), not "
                        f"padding. Then choose 3 short, punchy, VERBATIM quotes from the final "
                        f"Part 1 and Part 2 for reels.\n\n"
                        "Return JSON: {\"part1\":\"...\",\"part2\":\"...\","
                        "\"reels\":[{\"quote\":\"...\",\"segment\":\"part1\"}]}\n\n"
                        f"PART 1 ({p1_note}):\n{episode['segments'].get('part1', '')}\n\n"
                        f"PART 2 ({p2_note}):\n{episode['segments'].get('part2', '')}"},
                ],
            )
            data = json.loads(resp.choices[0].message.content)
        except Exception as exc:
            log("script", f"expand step failed ({exc}); keeping current length.")
            return
        # Only replace a part we actually asked to expand — never overwrite a
        # part that was already long enough (that's what caused the overshoot).
        if need1 and data.get("part1"):
            episode["segments"]["part1"] = _stringify(data["part1"]).strip()
        if need2 and data.get("part2"):
            episode["segments"]["part2"] = _stringify(data["part2"]).strip()
        reels = data.get("reels")
        if isinstance(reels, list) and reels:
            clean = []
            for r in reels:
                if not isinstance(r, dict):
                    r = {"quote": _stringify(r)}
                r["quote"] = _stringify(r.get("quote", ""))
                if r.get("segment") not in SEGMENTS:
                    r["segment"] = "part1"
                clean.append(r)
            episode["reels"] = clean[:3]

    c1 = len(episode["segments"].get("part1", ""))
    c2 = len(episode["segments"].get("part2", ""))
    log("script", f"teaching set to {c1} / {c2} characters (Part 1 / Part 2).")


_URL_RE = re.compile(
    r"""(?xi)
    (?:\b(?:at|to|via|visit|here|link)\b[\s:,-]*)?   # optional dangling lead-in
    (?:                                   # ---- one spoken-unfriendly link ----
        https?://\S+                      # http(s):// URLs
      | www\.\S+                          # www. URLs
      | \b\w[\w-]*\.(?:com|org|net|io|co|us|tv)\b(?:/\S*)?  # bare domains + path
    )
    """,
)

# Long standalone ID codes read aloud as letters (e.g. an Amazon ASIN B0H44JNLLL).
_CODE_RE = re.compile(r"\b(?=[A-Z0-9]*[A-Z])(?=[A-Z0-9]*\d)[A-Z0-9]{8,}\b")


def _strip_spoken_urls(text: str) -> tuple[str, int]:
    """Remove URLs / bare domains / ID codes from a spoken segment.

    Returns the cleaned text and how many things were removed. A link at the
    very end of a sentence is dropped; the surrounding words already say "find
    it on Amazon" / "the link is in the description".
    """
    if not text:
        return text, 0
    n = 0

    def _drop(_m):
        nonlocal n
        n += 1
        return ""

    out = _URL_RE.sub(_drop, text)
    out = _CODE_RE.sub(_drop, out)
    # Tidy up spacing/punctuation left behind (e.g. "grab it on Amazon: .").
    out = re.sub(r"[ \t]{2,}", " ", out)
    out = re.sub(r"\s+([.,;:!?])", r"\1", out)
    out = re.sub(r"[:;,]\s*([.!?])", r"\1", out)
    out = re.sub(r"[ \t]*[:;,\-]\s*$", ".", out, flags=re.M)  # dangling ": " at line end
    out = re.sub(r"\(\s*\)", "", out)
    return out.strip(), n


def _measure(text: str, wpm: int = 150) -> dict:
    """Word count and estimated spoken duration for a segment."""
    words = len(text.split())
    return {"words": words, "est_seconds": round(words / wpm * 60, 1)}


def _validate(ep: dict) -> None:
    for key in ("title", "tagline", "scripture", "summary", "segments", "reels"):
        if key not in ep:
            raise ValueError(f"Script model left out '{key}'. Re-run the script stage.")
    for seg in SEGMENTS:
        if not ep["segments"].get(seg, "").strip():
            raise ValueError(f"Script is missing the '{seg}' segment. Re-run script.")
    for reel in ep["reels"]:
        if reel.get("segment") not in SEGMENTS:
            reel["segment"] = "part1"  # be forgiving; clamp to a valid segment


# --------------------------------------------------------------------------- #
# Editor pass: a second, focused revision that makes each script excellent —
# it deletes cliches, cuts repetition, forces concrete named facts, and ends
# Part 2 on a tight verdict + one action. Editing real text is far more
# reliable than asking the first draft to obey every rule.
# --------------------------------------------------------------------------- #

_BANNED_CLICHES = [
    "beacon", "light in the darkness", "city on a hill", "cautionary tale",
    "stand firm", "speak truth to power", "conscience of society",
    "conscience of the state", "no matter the cost", "vigilant", "vigilance",
    "voice for the voiceless", "the very soul", "clarion call", "siren call",
]

# Deterministic swaps for single-word cliches the model keeps re-adding. Safe,
# whole-word, and applied after the AI edit so they can never survive.
_WORD_SWAPS = [
    (r"\bever vigilant\b", "watchful"),
    (r"\bvigilant\b", "watchful"),
    (r"\bvigilance\b", "watchfulness"),
    (r"\bsiren calls\b", "lures"),
    (r"\bsiren call\b", "lure"),
    (r"\bclarion call\b", "call"),
]


def _soften_words(text):
    out = text or ""
    for pat, repl in _WORD_SWAPS:
        out = re.sub(pat, repl, out, flags=re.IGNORECASE)
    return out


EDITOR_SYSTEM = """You are a ruthless line editor for the history podcast "Where Was the Church" (host Pastor Billy Daws). You are given Part 1 and Part 2 of an episode script. Revise them to be excellent and return STRICT JSON.

Do ALL of the following:
1. DELETE every one of these cliches and any close cousin, rewriting that sentence with a concrete, specific fact instead of another platitude: beacon; light in the darkness; city on a hill; cautionary tale; stand firm; speak truth to power; conscience of society/state; no matter the cost; vigilant / vigilance; voice for the voiceless; the very soul of a nation; clarion call; siren call.
2. CUT repetition. If two sentences make the same point, keep the sharper one and delete the other.
3. Where the writing is vague about what actually happened, SHARPEN it into concrete, named, dated specifics, using ONLY facts you are certain are historically accurate. NEVER invent a fact, date, name, or quotation.
4. Keep the voice reverent, plain, vivid, and accurate. Spoken words only: no URLs, no stage directions, and NEVER print labels, letters, numbers, or parentheses such as (a), (b), (1), or First/Second/Lastly, because every character is read aloud.

Return Part 2 IN PIECES so its verdict always lands last:
- "part2_body": the faithful remnant and the reckoning, named and concrete and vivid. It MUST read the episode Scripture ALOUD as the biblical measure — name the reference and speak the verse words in full (use the exact Scripture given in the user message), then a sentence showing how that Word judged the church's choice. Contains NO verdict and NO call to action.
- "verdict": exactly THREE short, sharp spoken sentences of what the church must never repeat, each tied to a concrete failure. Plain prose, no labels.
- "action": ONE clear, doable spoken sentence for the church today.
Do not put the verdict or the action anywhere inside part2_body.

Also choose exactly 3 short, punchy reel quotes, each taken VERBATIM (character for character) from your revised Part 1 or part2_body.

Return ONLY JSON:
{"part1":"<revised part 1>","part2_body":"<part 2 without verdict or action>","verdict":"<three sentences>","action":"<one sentence>","reels":[{"quote":"<verbatim>","segment":"part1"},{"quote":"<verbatim>","segment":"part2"},{"quote":"<verbatim>","segment":"part1"}]}"""


def _sentences(text):
    return [s for s in re.split(r"(?<=[.!?])\s+", text or "") if s.strip()]


def _remaining_cliches(text):
    low = (text or "").lower()
    return [c for c in _BANNED_CLICHES if c in low]


def _clean_reels(episode, proposed):
    """Keep only reel quotes that appear VERBATIM in a teaching segment; top up
    to three with punchy sentences pulled straight from the revised parts."""
    segs = episode.get("segments", {})
    out = []
    for r in (proposed or []):
        if not isinstance(r, dict):
            continue
        q = _stringify(r.get("quote", "")).strip()
        if not q:
            continue
        if q in segs.get("part1", ""):
            out.append({"quote": q, "segment": "part1"})
        elif q in segs.get("part2", ""):
            out.append({"quote": q, "segment": "part2"})
    if len(out) < 3:
        have = {o["quote"] for o in out}
        for seg in ("part1", "part2"):
            for s in _sentences(segs.get(seg, "")):
                s = s.strip()
                if 40 <= len(s) <= 180 and s not in have:
                    out.append({"quote": s, "segment": seg})
                    have.add(s)
                    if len(out) >= 3:
                        break
            if len(out) >= 3:
                break
    return out[:3]


def _spoken_ref(ref):
    """The reference as it should be read aloud — drop a trailing (KJV)/(NKJV)."""
    return re.sub(r"\s*\([^)]*\)\s*$", "", ref or "").strip()


def _ensure_scripture_in_body(episode, body):
    """Guarantee the episode Scripture is actually SPOKEN in Part 2. If the writer
    and editor both left it out of the body, append a plain, reverent reading of it
    so every episode measures the history against the Word — before the verdict."""
    sc = episode.get("scripture") or {}
    ref, text = _spoken_ref(sc.get("ref", "")), (sc.get("text") or "").strip()
    if not ref or not text:
        return body
    norm = lambda s: re.sub(r"\s+", " ", (s or "").lower())
    body_n = norm(body)
    probe = norm(text)[:24]
    if (probe and probe in body_n) or (norm(ref) and norm(ref) in body_n):
        return body  # already read aloud somewhere in the body
    reading = (f'Lay that against the Word. {ref} says, "{text}" '
               f"That was the measure the church was handed — and the measure it was weighed by.")
    return (body.rstrip() + "\n\n" + reading) if body else reading


def _polish_episode(client, cfg, episode, focus_cliches=None):
    p1 = episode["segments"].get("part1", "")
    p2 = episode["segments"].get("part2", "")
    if not p1 or not p2:
        return
    extra = ""
    if focus_cliches:
        extra = ("\n\nThis draft STILL contains these banned words — remove every one and "
                 "rewrite with a concrete fact: " + ", ".join(sorted(set(focus_cliches))) + ".")
    _sc = episode.get("scripture") or {}
    user = (
        f"Episode: {episode.get('title', '')}\n"
        f"Scripture (read this ALOUD in part2_body): {_sc.get('ref', '')} — \"{_sc.get('text', '')}\"\n"
        f"Summary: {episode.get('summary', '')}\n\n"
        f"Revise Part 1 and Part 2 per the rules and return the JSON.{extra}\n\n"
        f"=== PART 1 ===\n{p1}\n\n=== PART 2 ===\n{p2}"
    )
    log("script", "editor pass: cleaning cliches, padding, and the verdict...")
    try:
        resp = client.chat.completions.create(
            model=cfg.openai_model,
            response_format={"type": "json_object"},
            temperature=0.4,
            max_tokens=8000,
            messages=[{"role": "system", "content": EDITOR_SYSTEM},
                      {"role": "user", "content": user}],
        )
        data = json.loads(resp.choices[0].message.content)
    except Exception as exc:
        log("script", f"editor pass skipped ({exc}); keeping current draft.")
        return

    np1 = _stringify(data.get("part1", "")).strip()
    if len(np1) >= 1500:
        episode["segments"]["part1"] = _soften_words(np1)

    # Assemble Part 2 in code so the verdict + action are ALWAYS last.
    body = _stringify(data.get("part2_body", "")).strip()
    verdict = _stringify(data.get("verdict", "")).strip()
    action = _stringify(data.get("action", "")).strip()
    if len(body) >= 1200 and verdict:
        body = _ensure_scripture_in_body(episode, body)  # verse is spoken before the verdict
        part2 = body + "\n\n" + verdict + ((" " + action) if action else "")
        episode["segments"]["part2"] = _soften_words(part2.strip())
    else:
        alt = _stringify(data.get("part2", "")).strip()
        if len(alt) >= 1500:
            episode["segments"]["part2"] = _soften_words(alt)

    reels = _clean_reels(episode, data.get("reels"))
    if reels:
        episode["reels"] = reels
    log("script", "editor pass done — "
        f"Part 1/2 now {len(episode['segments']['part1'])}/{len(episode['segments']['part2'])} chars.")
